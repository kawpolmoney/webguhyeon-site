  4. 배포·인계도메인·호스팅·SSL·검색 등록까지 마치고, 고객님 계정으로 소유권을 넘겨 드립니다.

유상 · 범위 안내 후 진행

범위와 일정을 먼저 안내합니다

  • 홈페이지 리뉴얼(디자인·구조 개편)
  • 새 페이지 · 새 기능 추가
  • 회원 · 결제(PG) 시스템 연동
  1. 요청 접수메일로 수정사항을 전달합니다.
  2. 확인 및 안내작업 범위를 확인해 무상·유상 여부와 일정을 알려 드립니다.
  3. 작업 진행실제 코드를 수정하고 반영합니다.
  4. 완료 확인고객님 검수 후 최종 완료 처리합니다.

무상 기간(3개월)이 끝나도 자동으로 유료 전환되지 않습니다. 이후 수정 요청이 있을 때만 월 구독형 유지보수나 건별 비용을 안내해 드립니다.

운영 비용, 있는 그대로 안내합니다.

홈페이지를 운영하려면 매년 드는 실비용이 있습니다. 이윤을 붙이지 않고 그대로 알려 드립니다.

  • 도메인(인터넷 주소)1~2만원 / 년.com·.co.kr 등. 고객님 명의로 직접 등록·결제하고, 만료일은 저희가 미리 알려 드립니다.
  • 호스팅무료검증된 클라우드 인프라의 무료 플랜을 사용합니다.
  • SSL 인증서(https)무료무료 인증기관(Let's Encrypt)으로 별도 신청 없이 자동 발급·적용됩니다.

제작비와 월 관리비는 제작 범위에 따라 달라지므로 상담 후 안내해 드립니다.

자주 묻는 질문

병원·학원·산후조리원 홈페이지도 제작하나요?

네. 병원(피부과), 학원, 산후조리원, 중소기업용 샘플을 위에 공개해 두었습니다. 업종과 상황에 맞춰 상담 후 구성합니다. 병원은 의료광고 규정에 맞춰 시술 후기·전후 사진·가격 유인 표현을 쓰지 않는 방향으로 만듭니다(실제 적용 전 법 원문 확인 필요).

호스팅 비용을 안 내면 홈페이지가 사라지나요?

WEBGUHYEON은 검증된 무료 인프라를 사용합니다. 장기간(1주일 이상) 접속이 없으면 데이터가 잠시 대기 상태로 전환될 수 있는데, 요청 즉시 저희가 바로 복구해 드리고 데이터는 안전하게 보존됩니다. 사이트 자체가 사라지는 일은 없습니다.

타사에서 제작한 사이트도 유지보수만 맡길 수 있나요?

가능합니다. 다만 기존 코드 구조를 먼저 파악해야 해서 초기 분석 시간이 별도로 필요할 수 있습니다.

무상 기간(3개월)이 끝나면 자동으로 유료 전환되나요?

자동 전환되지 않습니다. 이후 수정 요청이 있을 때만 월 구독형 유지보수나 건별 비용을 안내해 드립니다.
